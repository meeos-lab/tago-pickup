# Tago UX 라이팅 가이드 (서비스 톤)

화면 글과 음성은 모두 **서비스 톤**이다. 운전자에게 차가 말을 거는 서비스이지, 친구가 아니다.
문자열은 `app/src/main/res/values/strings.xml`(한국어)·`values-en/strings.xml`(영어)에만 둔다. 코드에 글을 쓰지 않는다.

## 1. 톤 규칙
| 자리 | 문체 | 길이 | 예 |
|---|---|---|---|
| 헤드라인(상태 1줄) | 명사형 또는 "~까요?" 질문 | 20자 이내, 최대 2줄 | `GS25 앞으로 가는 중` · `누구를 데리러 갈까요?` · `지수 탑승 확인` |
| 보조 1줄 | 짧은 구를 `·`로 잇기. 문장이면 "~합니다/~하세요" | 2줄 이내 | `도착 2분 · 지수 걸어서 5분` · `가족에게 도착 알림을 보냈습니다` |
| 버튼·칩 | 운전자가 말할 답 그대로(칩) 또는 동사형 2~4어절 | 8자 이내 | `네, 거기로` · `다른 곳` · `내비로 안내` · `응급 끝내기` |
| 음성 안내 | 내비 안내체 "~합니다/~하세요". **한 번에 한 문장**, 거리·무엇·누가 확인·행동 순 | 2~3초 분량 | `전방 2.6km 사고 의심 구간. 차량 2대 급제동 후 정차 확인. 감속 후 차로를 확인하세요.` |
| 토스트 | "~했습니다" 한 문장 | 1줄 | `Irvine으로 바꿨습니다` |
| 카드 본문 | 명사형 줄 | 줄마다 1정보 | `도곡로 스타벅스 근처` · `정차 중` · `좌석 센서 3명 탑승` |

- 반말(`~했어요`, `~탔어요`)·감탄사·이모지·느낌표를 쓰지 않는다. 다만 **운전자가 말하는 답(칩)** 은 운전자 말투라 `네`/`괜찮아요`처럼 짧고 자연스럽게 둔다.
- 단정하지 않는다: 차가 모르는 것은 `감지`·`의심`·`확인 대기`로 쓴다(`탑승 감지` → 본인 확인 뒤 `탑승 확인`).
- 숫자는 단위와 붙여 쓴다: `2.4km`, `시속 80`, `5분`. 1km 미만은 100m 단위(`400m`).
- 사람 이름은 그대로, 호칭 조사는 `ro()`(로/으로) 같은 도우미로 붙인다.
- 영어는 같은 톤의 짧은 안내체: `Heading to GS25.` · `Pull over safely.` 대문자·느낌표 없음.

## 2. 용어 통일
| 쓰는 말 | 쓰지 않는 말 | 비고 |
|---|---|---|
| 만날 곳 | 만남 지점, 미팅 포인트 | 엔진·문서에서는 "만남 지점"을 써도 된다 |
| 타고 링크 | 네스토 링크, 링크만 | |
| 함께 가기 | 도로 링크, 컨보이 | "도로 링크"는 기술 용어(README·코드 주석)에만 |
| 가족 차 묶기 | 그룹 만들기 | |
| 다같이 휴게소 | 휴게소 제안 | |
| 탑승 감지 / 탑승 확인 / 하차 완료 | 탔어요 / 내렸어요 | |
| 응급 상황 / 응급 카드 | 긴급 상황 | "긴급차량"은 사이렌 차량에만 |
| 2열 오른쪽 문 | 뒷문 오른쪽 | 좌석·문은 "2열 왼쪽/가운데/오른쪽" |
| 안내 | 네비, 내비게이션 | 버튼은 "내비로 안내" |

## 3. 고친 예
| 전 | 후 |
|---|---|
| 지수 탔어요 | 지수 탑승 확인 |
| 지수 내렸어요 / 가족에게 도착 알림을 보냈어요 | 지수 하차 완료 / 가족에게 도착 알림을 보냈습니다 |
| 도로 링크 연결됨 · 주변 Tago 차 15대 | 함께 가기 연결됨 · 주변 차량 15대 |
| 약 3분 뒤 비 | 약 3분 후 비 예상 |
| 2열 오른쪽 탑승 감지. 가족에게 알렸고, 지수에게 확인을 요청했어요. | 2열 오른쪽 탑승을 감지했습니다. 가족에게 알리고 지수에게 확인을 요청했습니다. |
| 응, 거기로 / 다른 곳 | 네, 거기로 / 다른 곳 |
| 고르면 링크를 보내 만날 곳을 정해요 | 가족을 선택하면 타고 링크를 보냅니다 |
| 자리가 막혀 GS25 앞을 지나쳤어요. … 지수에게도 알렸어요. | 자리가 막혀 GS25 앞을 지나쳤습니다. GS25 대치학원점 앞으로 다시 정했습니다. 지수에게도 알렸습니다. |
