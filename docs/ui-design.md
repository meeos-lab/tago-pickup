# Tago 차량 화면 디자인 스펙

Pleos Connect **순정 설정 UI의 문법**을 그대로 따른다: 흰 바탕·검정 글자, 선택·주 동작은 검정 채움, 직각 모서리, 1px 회색 테두리, 얇은 구분선, 다크 테마는 짙은 회색 바탕에 밝은 회색 채움. 크기는 Pleos 디자인 가이드(`research_notes/pleos-ui-design-guide.md`)의 수치를 쓴다.
구현은 `app/.../ui/`(Jetpack Compose). 디자인 캔버스(Claude Design): https://claude.ai/artifact/Bcd9Lh5aH51iA4rq5ZdUZX — 아트보드와 이 문서, 코드의 토큰 값은 같다.

## 1. 화면과 원칙
- 대상: Connect-S-17 (2560×1440, 160dpi → 1dp = 1px). 앱 창 **가로 1682×1210**(단독, 왼쪽 853은 주행뷰), **세로 841×1210**(순정 내비와 1:1 분할 — 앱 창 가장자리의 ⋮ 손잡이를 안쪽으로 끌면 나뉜다. Tago 는 연 순서에 따라 왼쪽·오른쪽 어느 쪽에나 온다. 실측).
- 주행 중 화면 원칙(가이드): 1~2초 안에 파악, 조작 요소 **3개 이하**, 경고 글자 **32 이상**, 보조 글자 **26 이상**, 자동 애니메이션 없음.
- 터치 타깃: Large 버튼 높이 **100**, Medium **80**. 버튼 사이 간격 **16 이상**. 눌림은 95% 축소(80ms) + 면 색 변화.
- 한 화면 = **상태 1줄(헤드라인) + 보조 1줄 + 이 상태에서 누를 버튼**. 설명·로그·개발 정보는 보이지 않는다(브랜드 글자 길게 누르면 개발 패널).
- 바탕·글은 흑백. 색은 뜻이 있는 곳에만: 위험·응급 `red`, 주의 `orange`, 확정·원활 `green`, 비·내 위치 `blue`, 연기·내리막 `purple`. 색만으로 뜻을 전하지 않는다(아이콘 + 글 병기). 대비 4.5:1 이상.
- 지도 영역은 순정 내비와 같은 문법: 옅은 바탕(다크 `#3C4250`)에 흰 도로, 빨간 경로, 파란 내 차(퍽). 순정 내비의 안내 카드(TBT·도착 정보)는 흉내 내지 않는다. 지도 위 표기(퍽·라벨·선·반경)는 §9.

### 다른 Pleos 디스플레이 (dp 기준, `research_notes/pleos-ui-design-guide.md`)
| 디스플레이 | 앱 창 가로 | 앱 창 세로 | 배치 |
|---|---|---|---|
| Connect-S-17 (2560×1440, 160dpi) | 1700×1184 | 840×1184 | 가로: 패널 680 / 세로 |
| Connect-S-14.6 (2048×1152, 200dpi) | 1360×948 | 672×948 | 가로: 패널 600 / 세로 |
| Connect-L-12.9 (1920×1080) | 1274×855 | 628×855 | 가로: 패널 600 / 세로 |
| Connect-W (3840×1440·850) | 1640×1400·810 | 800×1400·810 | 가로: 패널 656 / 세로 |
| Connect-WF (3072×816, 200dpi) | 1256×800 | 648×800 | 가로: 패널 600 / 세로 |

- 모든 치수는 dp 라서 밀도가 달라도(160·200dpi) 같은 크기로 보인다. 가로 배치의 상태 패널은 **창 폭의 40%(600~680)** — 좁은 창에서도 지도가 패널보다 넓다. 세로 배치 기준은 1200dp 미만.
- 한글은 어절 단위 줄바꿈(`LineBreak.Heading`): 좁은 창에서 "주세/요"처럼 음절이 끊기지 않는다. 버튼 글이 한 줄에 안 들어가면 좌우 패딩만 40 → 16 으로 준다(높이·간격은 그대로).
- 지도 범례는 항목 사이에서만 줄이 바뀐다(항목 안은 줄바꿈 없는 공백).
- 확인 방법(디버그·시연 빌드): `adb shell am start -n ai.meeos.tago/.MainActivity --es frame 628x855` — 앱 창을 그 크기(dp)로 줄여 회색 바탕 위에 그린다(에뮬레이터 화면 설정은 그대로). `--es frame 0` 으로 원래대로. 2026-10-31 위 8가지 창에서 대기·픽업·응급 화면을 캡처해 확인했다.

### 세로 841×1210 (내비와 분할)
- **데리러 가기**(만날 곳·경로·아이 위치가 지도에 있다)만 상태 영역 위(내용만큼, 최대 **74%**) + 지도 아래 나머지.

## 7. 모션·피드백
- 버튼 눌림 95% 축소 80ms + 면 색. 화면 요소 등장은 전환 없이 바로(반복·펄스·마키 금지).
- 입력 뒤 0.25초 안에 화면이 바뀐다(버튼을 누르면 칩을 바로 숨기고, 서버 응답은 비동기).
- 주/야간 전환(uiMode)은 액티비티를 다시 만들지 않고 토큰만 바꾼다(`android:configChanges="uiMode"`). 지도 페이지는 앱이 URL 로 알려 주는 `?dark=1` 로 `body.dark` 를 켜 바탕 지도를 야간(dark) 스타일로 바꾼다(WebView 의 `prefers-color-scheme` 는 믿지 않는다. `#map` id 규칙이 `.leaflet-container` 규칙보다 세므로 빈 바탕색은 `body.car.dark #map` 으로 덮는다). 바탕 지도 자체는 §9.

## 8. 휴대폰 페이지 (`server/rider.html` · `server/link/link.html`)
기다리는 사람(`/m/<세션>`)·보호자(`/f/<세션>`)·함께 가기 참가자(`/link/<그룹>`) 페이지도 차 화면과 **같은 문법·같은 토큰**이다. 캔버스 "휴대폰" 줄(390×844)과 같다.
- 구성(위→아래): 브랜드 `Tago`(14 bold) → **상태 한 줄**(26/34 bold) → **보조 한 줄**(15/22 `text2`) → **진행 표시**(링크 → 만날 곳 → 도착 → 탑승, 차 앱 Stepper 와 같다) → **지도**(360, 1px `line`, 출처만) → **이 상태에서 누를 버튼**. 설명·이유·정차 한도·제외 지점·범례는 "왜 여기인가요?" 아래에 접혀 있다. 기록(로그)은 `?dev=1`에서만.
- 상태 한 줄이 곧 안내다(배너 없음): 위치 공유 전 "지수, 위치를 공유해 주세요" → 제안 "GS25 앞에서 만나요 / 걸어서 2분 · 차 2분 후 · 정차 2분까지" → 확정 "GS25 앞에서 만나요" · 나올 때 "지금 나오세요" → 도착 "차가 도착했어요 / GS25 앞에 서 있어요" → 탑승 감지 "차에 탔나요?" [제가 탔어요] → "지수 탑승 확인" → "지수 하차 완료"(탑승·하차 뒤에는 시연 줄·설명이 사라진다). 차가 확정 지점을 지나쳐 다시 정하면 "만날 곳이 바뀌었어요 / 바나프레소 대신 GS25 · 걸어서 2분" + [GS25로 갈게요]. 응급 중에는 "오늘 픽업은 조금 늦어져요"만(의료 정보 없음).
- 한국어 단어는 중간에서 끊지 않는다(`word-break: keep-all`). 어르신 링크(`body.senior`)는 글·버튼이 한 단계 크고, 원탭 메시지 세 개는 세로로 쌓인다(캡처 docs/15, 58–61).

## 9. 지도 표기 (순정 내비 문법 · 캔버스 "지도 표기" 보드)
차 화면·휴대폰·보호자·함께 가기 지도가 모두 같은 표기를 쓴다(`rider.html` `.mk-*`, `link.html` `.carpin/.rest/.hz`).
- **차 화면 지도 = 네이티브 TMAP SDK**(`app/.../map/TmapCarMap.kt`, TMAP Android SDK 3.7 · `app/libs`): 앱키가 있으면 픽업 차 화면(`/car/`)은 WebView 대신 `TMapView` 로 그린다. 내 차는 SDK 에 든 순정 커서 그림(VSM `location_marker`: 흰 원 + 파란 화살표)을 마커로 올려 진행 방향으로 돌리고(엔진 회전 = 정북에서 시계 방향), 노선은 SDK `TMapTrafficLine`(티맵과 같은 교통 색 + 진행 방향 화살표, 데이터는 티맵 경로 API). 목적지(추천·확정 만날 곳)는 SDK 의 '도착' 핀(`end.png`), 경유지는 '경유' 핀(`pass.png`). SDK 에 없는 마커는 사용자가 만든 **v9 세트**(캔버스 "지도 마커 (v9 적용 세트)" 보드, `res/drawable-nodpi/tago_place_*`·`tago_person_*`·`tago_pin_*.png`, 192×192 = 기준 48 의 4배·투명, 단색 물방울 + 흰 실루엣, 광택·그림자 없음)를 쓴다. 모든 핀은 끝점이 위치(앵커 0.5, 0.896). 대안 후보 = 후보 종류(엔진 `icon`)별 핀 31종(편의점·카페·약국·주차장 입구·지하철 출구 + 패스트푸드·빵집·은행 등 26종, 학원은 학교 그림, 그림이 없는 종류는 원형 퍽) 67 px, 기다리는 사람 = 아이·어른·어르신 사람 핀 67 px, 단속 CCTV(심야는 달 배지)·제외 = 작은 회색 핀 38 px. SDK 도착 핀(48×62)보다 대안 핀을 조금 작게 둬 목적지가 먼저 보인다. 지금 후보 데이터에 있는 종류는 편의점·카페·약국·주차장·지하철·학원뿐이라, 나머지 26종은 그림만 연결돼 있고 영업·개방 시간 규칙과 함께 후보 데이터를 넣으면 나온다. 손 조작: 운전자가 지도를 만지면 20초 동안 자동 맞춤을 멈추고 오른쪽 위에 '다시 맞추기' 아이콘 버튼(80dp, 직각)을 띄운다. 달리는 중에는 손 이동·확대를 막고(보기 전용), 두 손가락 회전·기울임은 늘 끈다. 앱키 확인이 15초 안에 끝나지 않으면(오프라인 시동) 웹 지도로 넘어간다. 티맵 경로는 목적지가 바뀔 때와 달리는 중 60초마다만 받고, 실패(429·오프라인)하면 5분 쉰다. 주간 `DEFAULT`·야간 `NIGHT`, 가게 아이콘은 끄고 지명만(엔진 `setPOIIconScale(0)`, 지명 1.4배). 퍽·라벨·반경·범례는 아래 규칙 그대로 비트맵으로 그린다(웹 지도와 같은 크기 = 1.375배). 겹침은 엔진 priority 가 작을수록 위. 인증 실패·키 없음이면 웹 지도로. 휴대폰·함께 가기는 웹 그대로.
- **차 화면 지도 조작 버튼 배치**(순정 내비 실측 2026-11-01: 오른쪽 아래 정사각 버튼 세로 열, 가운데 아래 "⊕ 내 위치로" 글자 버튼, 오른쪽 위 2D/나침반): **줌 슬라이더는 오른쪽 아래**(여백 24), **다시 맞추기는 가운데 아래 글자 버튼**(▲ 아이콘 32 + Label M bold, 높이 80, 손으로 만진 뒤에만), **범례는 왼쪽 위**, TMAP 로고는 왼쪽 아래.
- **줌 슬라이더**(지도 앱의 세로 막대, 폭 80): 위 + 상자(80) · 트랙(240) 위의 손잡이(80×40, ink 채움) · 아래 − 상자(80), 사이 12. **손잡이를 위로 올리면 확대, 내리면 축소**(연속, 지도 가운데 기준), 트랙을 누르면 그 자리로, + / − 는 한 레벨씩 애니메이션. 범위 줌 10(도시)~19(골목). 자동 맞춤·두 번 탭 등으로 SDK 줌이 바뀌면 손잡이가 따라온다. 달리는 중에는 숨김.
- **차 화면 지도 손 조작**: 한 손가락 끌기는 SDK 그대로. 확대·축소는 위 슬라이더와 **두 번 탭 뒤 누른 채 위아래 드래그**(퀵 스케일 — 안드로이드 지도 표준: 아래로 = 확대, 위로 = 축소, 탭한 점 기준. 손가락·마우스 하나로 되는 유일한 연속 확대 제스처라 에뮬레이터에서도 된다. 두 번째 탭은 첫 탭에서 40~300ms 안). 두 손가락 핀치도 앱이 받아(`TmapCarMap.view`) VSM 엔진 `setMapScale(배율, 기준점)` 으로 확대·축소한다 — 기준점은 손가락 중심이 지도 안(가장자리 10% 안쪽)이면 그 점, 밖이면 지도 가운데(실차용). 버튼을 둔 이유: 에뮬레이터 핀치(Ctrl+드래그)는 두 번째 손가락을 **에뮬레이터 화면 전체(2560)의 중심 대칭**(x = 2560 − 마우스 x)에 두는데, 마우스가 지도 위에 있으면 그 점은 왼쪽 주행뷰 창이나 우리 상태 패널에 떨어져 **지도 view 에는 손가락 하나만 온다**(2026-11-01 콘솔 raw 터치로 실측 — 주행뷰면 다른 창, 상태 패널이면 Compose 가 포인터를 나눈다). 즉 에뮬레이터에서는 어떤 앱도 핀치로 지도를 확대할 수 없고, 에뮬레이터 설정에 중심점 옵션도 없다. 전에 SDK 핀치가 켜져 있을 때 "엉뚱한 곳으로 가던" 것은 지도 밖 기준점으로 확대·끌기가 섞인 결과. 회전·기울임은 끔, 달리는 중에는 끌기·핀치·버튼 모두 잠금(버튼은 숨김). 시험(디버그·시연 빌드): `adb shell am start -n ai.meeos.tago/.MainActivity --es gesture in|out|drag|dtap|dtapup` — 에뮬레이터식 핀치(두 번째 손가락 = 화면 중심 대칭)·끌기·두 번 탭 뒤 아래/위 드래그를 앱 안에서 흉내 낸다(`adb shell input` 은 두 번 탭 간격이 12ms 라 더블탭으로 안 잡힌다).
- **바탕(TMAP 웹)**: `local.properties` 에 `tmap.appKey`(openapi.sk.com TMAP Free 요금제)가 있으면 빌드가 HTML 의 `__TMAP_KEY__` 자리에 끼우고, 지도는 TMAP Vector JS(`Tmapv3`)의 공식 테마를 쓴다 — 주간 `ROAD`, 야간 `NIGHT`. 순정 내비처럼 가게·건물 POI(편의점·카페·은행…)는 끄고 도로·도로명·일방통행·유턴·지하철역·공원만 남긴다(엔진의 분류별 `display:off`, 공개 문서에 없는 API 라 실패해도 지도는 그대로). 차 화면은 도로명 글자 1.4배. 그리는 코드는 어댑터 `MapApi` 하나(퍽 = `iconHTML` 마커, 선 테 = 더 굵은 선을 밑에, 점선 = `strokeStyle:"dash"`, 줌은 GL 엔진이라 Leaflet 숫자보다 1 작게). "powered by T map" 로고가 늘 붙어 출처 줄은 두지 않고, 차 화면 공공데이터 출처는 범례 아래 작은 줄. 에뮬레이터 WebView 는 WebGL1 이 막혀 있어(WebGL2 만 됨) WebGL1 요청이 실패할 때만 WebGL2 컨텍스트를 돌려준다(엔진 셰이더가 GLSL ES 1.00 이라 그대로 돈다).
- **바탕(키가 없을 때)**: OpenFreeMap 벡터 타일(MapLibre GL, Leaflet 의 타일 칸에 `maplibre-gl-leaflet` 로 깐다. 키·워터마크 없음. MapLibre 는 이 경로에서만 불러온다). 주간은 `positron`(바탕 `#F2F3F0` + 흰 도로), 야간은 `dark`(바탕 `#0C0C0C` + 회색 도로) 스타일을 그대로 쓰고, 라벨만 한글(`name:ko`)로, 야간 글자색은 `#9E9E9E` 로, 차 화면은 글자를 1.4배로 바꾼다. 필터·투명도는 걸지 않는다 — 래스터 OSM 타일을 회색조·투명도로 누르던 때는 2560px 차 화면에서 뿌옇고 번졌다. 줌 버튼 없음, 출처는 한 줄(`© OpenFreeMap © OpenMapTiles © OpenStreetMap`), 공공데이터 출처는 "왜 여기인가요?" 범례에. 인터넷이 없으면 지도 데이터의 도로 선으로 바탕을 직접 그린다.
- **퍽**(원 가운데가 위치, 흰 테 3px, 그림자 없음 — 물방울 핀 없음): **나는 파랑** — 차 화면의 내 차는 순정 내비·티맵 커서와 같은 **흰 원 + 파란 화살표**(44, 옅은 테 1px, 주야간 같다), 휴대폰의 내 위치는 `#0064FF` 원 + 흰 사람(36), **상대는 `ink`**(차 화면의 아이, 휴대폰의 차 — 36), **추천** 흰 면 + 4px `green` 테 + green 글리프(48), **만남 확정** `green` 채움 + 흰 글리프(48, 확정 뒤 지도에 남는 유일한 색), **대안·경유** 흰 면 + 4px `orange` 테(40/36), **제외·단속 CCTV** 24 흰 면 + 2px `#9E9E9E` 테(제안 중에만, 누르면 이유).
- **라벨**: 흰 면 + 2px 뜻 색 테두리 + 진한 글, 직각(추천·확정 위, 대안·경유 아래). 야간은 `#1C1C1C` 면 + 밝은 글(검정 바탕 지도 위에서 한 단계 떠 보인다).
- **노선**(순정 내비·티맵 노선): 파랑 `#0064FF` + 진한 파랑 테 `#0046B4`(차 화면 10/14, 휴대폰 7/11) 위에 진행 방향 흰 꺾쇠(차 80px · 휴대폰 60px 간격, 줌이 바뀌면 다시 찍는다). 막히는 구간만 색을 바꾼다 — 서행 `orange`(테 `#B35F00`), 지체 `#FF6A00`, 정체 `red`(테 `#A8180F`). 원활·정보없음은 파랑. 테를 모두 먼저 깔고 색을 올려 구간 이음매에 테가 비치지 않게 한다.
- **노선 데이터**: TMAP 바탕이면 차 → (경유지) → 만날 곳을 티맵 자동차 경로 API(`trafficInfo: Y`, 차가 보는 방향 우선)로 받는다. 목적지·경유지가 바뀔 때와 60초마다만 부르고(무료 한도 일 1,000건) 저장하지 않는다(약관: 24시간 넘게 쓰지 않음). 키가 없거나 못 받으면 엔진이 도로망으로 찾은 경로를 같은 모양(파랑)으로 그린다. 내 차 커서는 TMAP 웹 SDK 에 그림으로 들어 있지 않아(내장 아이콘은 출발·도착 핀과 점뿐) 같은 모양을 직접 그린다.

- **차 화면 범례**: 지도 왼쪽 아래 흰 면 + 1px `line` (소화전 5m · 버스정류장 10m · 횡단보도 10m), 제안 중에만.
